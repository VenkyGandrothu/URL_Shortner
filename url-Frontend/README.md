# Shortner Frontend

React + Vite (JavaScript only) UI for the URL shortener backend.

## Run

1. Start the Spring backend on port `8080`
2. From this folder:

```bash
npm install
npm run dev
```

3. Open `http://localhost:5173`

## API

Uses `http://localhost:8080` by default.

Optional env file `.env`:

```
VITE_API_BASE=http://localhost:8080
```
